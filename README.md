## 智能体能干什么

这不是一个聊天机器人，而是一个**会自己调用工具干活的智能体**。它能做的事包括：

### 一、直接操作你的设备

- **控制手机**：读写手机文件、运行脚本、查系统信息，智能体直接动手完成，不只给建议
- **遥控电脑**：Termux 桥接通道直通 PC 端主仓智能体——人在外面，用手机就能指挥家里的电脑改代码、跑脚本、整理文件

### 二、智能体内置工具箱（与 PC 版同一套）

- **文件操作**：读、写、查找、批量替换、目录树浏览，智能体可以直接改你项目里的代码
- **代码执行**：跑 Shell 命令、执行 Python 脚本、定时任务，跑完自己检查结果
- **信息检索**：全局搜索、正则匹配、网页抓取——要查资料它自己去查
- **浏览器自动化**：内置浏览器能打开网页、截图、点击、填表、登录，帮你在网页上办事
- **AI 多模态**：文字生成图片、视频生成、发邮件通知
- **写作辅助**：40+ 写作工具——改写润色、纠错校对、摘要提取、SEO 优化、全文生成

### 三、记忆系统（越用越懂你）

- **项目记录**：任务背景、决策、结论落盘存档，换一次对话也不会忘
- **长期记忆**：你的偏好跨对话记住，不用每次重新交代
- **超长计划**：大型任务拆成计划文件，跨对话接力执行，做一半关掉 App 下次接着来
- **站点记忆**：常用网站的经验自动沉淀，越用越熟练

### 四、多智能体协作

- **蜂群模式**：多个智能体窗口并行开工，各有分工，收口汇总互相审核
- **红队反驳**：结论先过反驳师、审核员，被驳倒就返工，答案更可靠

## 为什么做这个项目

PC 端智能体已经很强，但人不会一直坐在电脑前。**峰控手机智能体**把这套完整能力装进 Android 手机：

- **同一大脑** — 直连社区 LLM / 自有 API，手机端与 PC 端共享账号与上下文
- **界面零开发** — Android WebView 壳直接加载智能体 Web UI，PC 端界面升级手机端自动跟进
- **原生能力桥** — 通过 `NativeBridge (window.ZFMobile)` 暴露原生接口，调用手机原生能力
- **独立仓库** — 独立文件夹 + 独立 git，独立演进不受 PC 版发版节奏拖累

## 构建

- Android Studio 打开根目录直接 Run；或命令行 `gradlew assembleRelease`
- 服务器地址：模拟器 `10.0.2.2` / 真机与 PC 同一局域网 IP / 云端正式服务器

> 签名使用本地 `zf.keystore`（已由 `.gitignore` 排除，**不随仓库分发**，请自行离线备份），与历史版本同源，可直接覆盖升级。
